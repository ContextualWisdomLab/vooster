# Finding — `vspec doctor` returned 404

The dogfood snapshot tracked this as A2, with B5 as the direct consequence:
multiple API responses suggested `vspec doctor`, but the API did not register
`GET /v1/doctor`, so the CLI surfaced a bare 404 `ApiError`.

## Resolution

Implemented a server-backed doctor route and wired the CLI's existing doctor
command through it. The route returns a structured diagnostic for a project or
use case, including quality checks and fix commands for missing Cockburn fields.

Verification:

- `pnpm exec vitest run apps/api/tests/e2e/doctor-route.test.ts --passWithNoTests=false`
- `pnpm exec vitest run apps/cli/tests/e2e-cli-honest/doctor.test.ts --passWithNoTests=false`
