## 2024-05-18 - Added Loader2 spinner to async dialog submit buttons
**Learning:** Providing immediate visual feedback during async form submission in Dialogs significantly improves perceived responsiveness and prevents duplicate clicks by clearly indicating the loading state to the user.
**Action:** Consistently add a visual loading indicator (like an animated spinner) and a disabled state to submit buttons in all components that handle asynchronous requests, particularly in dialogs and forms.
